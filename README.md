# Baillie O'Grady - Portfolio

A lightweight portfolio site built with Parcel, Tailwind CSS, and custom fonts.

## Dev workflow

```bash
npm install
npm run dev
```

Parcel will serve the site at `http://localhost:1234` with hot reload enabled.

## Build

```bash
npm run build
```

Output goes to the `dist/` directory.

## Stack

- **Parcel** — Zero-config bundler with auto-reload
- **Tailwind CSS** — Utility-first styling
- **PostCSS** — Autoprefixer support
- **Custom fonts** — Open Sans & Bebas Neue (WOFF2)
